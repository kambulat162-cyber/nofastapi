# Консольный каталог

Программа работает локально, без API, сервера и сторонних библиотек.
Требуется Python 3.10 или новее.

Запуск из папки проекта:

```console
python main.py
```

На Windows также можно использовать `py main.py`.
Выберите действие в меню: добавление, просмотр и поиск пользователей
или товаров, создание заказа и поиск заказов по пользователю или датам.
Заказ привязан к пользователю и содержит позиции с количеством и ценой товара
на момент оформления.
Для выхода введите `0`. Ctrl+C также завершает программу.

Данные пользователей, товаров, заказов и позиций заказов сохраняются в `demo.db`
рядом с `main.py`, независимо от папки запуска.
Существующая база сохраняется: недостающие поля пользователей добавляются
автоматически при первом запуске. Старое поле возраста и таблицы видео остаются.
Дата рождения вводится в формате `ГГГГ-ММ-ДД`, цена — в целых рублях.
Телефон и дату рождения можно пропустить. Пароли сохраняются в виде хешей
с индивидуальной солью и не выводятся в списке. Авторизации в программе нет.

Если прежняя `.venv` ссылается на отсутствующий Python другого компьютера,
выберите установленный Python 3.10+ в настройках интерпретатора IDE.
Для этой программы виртуальное окружение и установка пакетов не нужны.
